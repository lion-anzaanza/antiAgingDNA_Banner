# spec.md — LifeDNA 사전예약 랜딩페이지

## 화면 구성

1. **랜딩페이지** (`/`, 1개 페이지, 스크롤형)
   - 히어로: LifeDNA 워드마크 + 한 줄 소개("매일의 기록으로 나를 유전자처럼 읽어내는 웰니스 앱") + "Coming Soon" 배지 + 이메일 입력 폼
   - 문제 제기: 웰니스 앱을 여러 개 써봤지만 기능이 파편화되어 있고, 통합 플랫폼도 대부분 웨어러블 디바이스가 있어야 쓸 수 있다는 공감 포인트
   - 핵심 개념: 🧬 나만의 웰니스 유전자 + 🔮 살아있는 컨디션 오브 (2개 카드)
   - 이용 방법: 4단계 카드 — 01 초기 진단(온보딩 12문항) → 02 매일 일지(60초 선택형 기록) → 03 종합 점수(컨디션·5영역 점수) → 04 맞춤 개선책(오늘의 한 가지 제안·실천 추적)
   - 시그니처 기능 소개: 2개 카드
     - **LifeDNA Pair (1:1 관리)**: 친구·연인과 짝을 맺어 관리. 내가 실천하면 상대에게 혜택, 상대가 실천하면 내 보상 조건 달성되는 상호 보상 구조. 1:1 점수 대결(라이벌), 공동 루틴(식사·운동·수면), 공동 목표·리포트·보상
     - **동네 크루 (동네생활·동네 챌린지)**: 지역 기반 커뮤니티. 동네별 걷기·러닝 공동 목표, 동네 러닝 모임. 소규모는 커플·가족 전용 루틴+공동 리포트, 중/대규모 크루는 크루장에게 회원·출석 관리 권한
   - FAQ: 아코디언(눌러서 펼치는 목록) 4개 — 웨어러블 필요 여부 / 결제 필요 여부 / 이메일 사용 목적(개인정보처리방침 링크) / 출시 시점(Coming Soon)
   - 하단 CTA: 이메일 입력 폼 (히어로와 동일 폼 재사용)
2. **신청 완료 화면** (같은 페이지 내 상태 전환, 별도 라우트 아님)
   - "감사합니다" 메시지
   - 공유 유도: 카카오톡/링크 공유 버튼 + 미리 작성된 공유 문구 (순번 추적·보상 로직 없음)
3. **개인정보처리방침 페이지** (`/privacy`, 별도 페이지)
4. **관리자 페이지** (`/admin`, 별도 페이지) — 비개발자(동업자)가 Supabase 계정 없이 신청자 명단을 보기 위한 화면
   - 미로그인: 비밀번호 입력 폼 하나. 틀리면 안내 문구
   - 로그인 후: 총 신청자 수 + 이메일·신청일시 표. 30초마다 자동 새로고침
   - 로그아웃 버튼
   - **의도적으로 넣지 않는 것**: 검색·정렬·CSV 내보내기·통계·차트, 명단 편집·삭제, 계정 가입. 명단 수정이 필요하면 Supabase 대시보드에서 한다
   - 검색엔진에 노출되지 않도록 `noindex` 처리

## 기능

- 이메일 입력 → 형식 검증(정상적인 이메일 형식인지만 확인) → Supabase에 저장
- 중복 이메일로 재신청 시: 에러로 막지 않고 "이미 신청하셨어요" 안내
- 신청 완료 시 공유 버튼 노출
- 봇/스팸 방지, 대기 순번 추적·보상 로직은 이번 범위에서 제외 (나중에 필요하면 추가)

## 데이터 (Supabase)

- `waitlist` 테이블
  - `email` (고유, unique)
  - `created_at`
- 그 외 개인정보(이름, 연락처 등)는 수집하지 않음
- RLS 때문에 공개 키로는 명단을 읽을 수 없으므로, `/admin`은 서버에서만 쓰는 secret key로 조회한다
  (`lib/supabase-admin.ts`. 클라이언트 컴포넌트에서 절대 import하지 않는다)
- `/admin` 인증: 비밀번호(`ADMIN_PASSWORD`)가 맞으면 서명값만 담은 httpOnly 쿠키를 7일간 발급.
  비밀번호 자체는 쿠키에 담지 않는다. 계정·세션 테이블은 없다

## 걱정되는 점 & 확인 방법

- 출시 시점은 "Coming Soon"으로만 표기, 구체적 날짜는 약속하지 않음
- 봇/장난 이메일 신청은 이번 단계에서는 신경 쓰지 않음
- 방문자 수는 Vercel Analytics(쿠키 없는 집계)로 확인 → 신청 수(Supabase `waitlist`)와 비교해 전환율을 본다
- 완료 확인 방법:
  - `npm run build`가 오류 없이 끝나는지 확인
  - 모바일 폭(약 400px)에서 이메일 입력 → 제출 → 완료 화면 → 공유 버튼까지 직접 눌러서 확인
  - `/privacy` 페이지 접속 확인
